# LearnSite 平台配色规范（三套主题方向）

> 状态：已落地。三套方向同时存在于主题抽屉，默认 **墨绿画布（emblem）**。
>
> 实现分两层，改主题时按层找文件：
> - **调色**：`apps/web/src/styles/theme.css` —— 每套主题一段 `--ls-*` 变量块，外加正交的 `[data-scheme='dark']` 深色块。
> - **造型**：`apps/web/src/styles/theme-directions.css` —— 壳层深浅、页头形态、卡片浮起方式、模块功能色落在哪些元素上。
>
> 两层的分工是硬约束：颜色只写在 theme.css，形状只写在 theme-directions.css，不要在组件里按主题写 if。

## 为什么是这三套

旧版界面最大的问题不是「颜色不够亮」，而是**整页只有两个白**：像素统计里教师端 91.1%、学生端 96.4% 是近白，真正有彩度的面积只有 0.4%~1.2%，卡片（`#ffffff`）与画布（`#f6f9f7`）对比 1.06:1。三套方向分别用三种办法解决同一个问题：

| 方向 | 解决思路 | 彩度从哪来 |
| --- | --- | --- |
| 墨绿画布 | 不加颜色，先把「纸」和「桌面」分开 | 壳层与页头色带的大面积深绿 |
| 科目色谱 | 活泼来自语义而不是浓度 | 每页一个模块功能色，落在导航图标块、页头竖标、卡片顶边 |
| 粘土童趣 | 颜色升级为面积色，形状变软 | 橙色缎带、实心橙按钮与导航、奶油点阵底 |

## 方案总览

| 方案 | 代码 | 主色 | 强调色 | 定位 | 默认 |
| --- | --- | --- | --- | --- | --- |
| 墨绿画布（Ink Rail） | `emblem` | `#1E7A57` | `#C9A469` | 深墨绿壳层 + 纸白墨线卡片，正式、耐看 | 是 |

## 方向一 · 墨绿画布（emblem）

深色只出现在壳层与页头色带，内容区一律纸白；卡片靠 1px 墨线而不是阴影浮起来。

| 语义 | 色值 | 用途 |
| --- | --- | --- |
| 壳层深墨绿 | `#12362B` | 侧栏、顶栏、页签条、页头色带 |
| 壳层深墨绿-深 | `#0C2A1F` | 侧栏渐变收尾 |
| 画布（鼠尾草） | `#E6ECE6` | 页面底色 |
| 卡片 | `#FFFFFF` | 卡片、弹窗、表格 |
| 墨线边框 | `rgba(18,54,43,.16)` | 卡片描边、分隔线 |
| 正文 / 标题 | `#26362D` / `#12362B` | 正文与标题 |
| 次要文字 | `#5F7168` | 说明、时间戳 |
| 主色 | `#1E7A57` | 主操作、链接、进度 |
| 描边金 | `#C9A469` | 页头色带下沿 3px 金线、色带上的主按钮 |

造型规则：

1. 圆角收紧：`--ls-radius-sm/md/lg` = 6 / 8 / 10px，卡片不再是大圆角软块。
2. 页头 = 整幅色带：`.hero-panel.sa-page-header` 与 `.sf-page-head` 都向外出血（`--ls-bleed-x` 与 `.sb-content` 的 padding 对齐），底部 3px 金线；标题白色、说明 `rgba(226,240,232,.72)`。
3. 色带上的按钮：次要=半透明白描边，主操作=金底墨字。
4. 卡片：`1px` 墨线 + 无阴影 + 无毛玻璃；`.sf-panel` 同规则。
5. 导航选中项左侧 2px 金线（`inset 2px 0 0 var(--ls-accent)`）。

## 方向二 · 科目色谱（growth）

主操作仍只有校徽绿一种；其余色相只表示「这一页属于哪个模块」。

| 模块组 | 色值 | 覆盖路由 |
| --- | --- | --- |
| 总览 / 学案 / 学生 | `#1E7A57` | `/staff`、`/staff/lesson-plans`、`/staff/students`、`/student`、`/student/courses` |
| 课程 / 报告 | `#0E7C86` | `/staff/curriculum`、`/staff/learning-reports` |
| 课堂 | `#2563B8` | `/staff/classroom` |
| 测验 / 考勤 | `#C2600F` | `/staff/quizzes`、`/staff/attendance` |
| 资源 / 助手 | `#6B4EAA` | `/staff/resources`、`/staff/assistants`、`/student/drive` |
| 提交 / 打字 / 评阅 | `#B23A48` | `/staff/submissions`、`/staff/typing`、`/student/work`、`/student/reviews` |
| 系统 | `#5C6F64` | `/staff/admin` |

| 语义 | 色值 |
| --- | --- |
| 画布 | `#DCE7DF` |
| 卡片 | `#FFFFFF` |
| 边框 | `rgba(18,50,36,.14)` |
| 正文 / 标题 | `#23332B` / `#16261E` |
| 次要文字 | `#5C6F64` |

造型规则：

1. 壳层 `SoybeanShell` 按路由算出 `data-module`，CSS 只认 `--ls-module`，不要在页面里写颜色。
2. 页头 = 白底 + 左侧 4px 功能色竖标（`.hero-panel.sa-page-header` / `.sf-page-head`）。
3. 卡片 = 白底 + 1px 线 + 3px 功能色顶边（`.sa-panel` / `.soft-card` / `.sf-panel`，62% 混白）。
4. 导航图标块：`.sb-nav-icon` 浅色块 + 功能色图标，选中态反白（实心功能色 + 白图标）。
5. 圆角 8 / 10 / 12px，无阴影。

## 方向三 · 粘土童趣 2.0（clay）

橙色从「点缀」升级为「面积色」；蓝色只做第二语义。

| 语义 | 色值 | 用途 |
| --- | --- | --- |
| 奶油底 | `#FFF4E6` | 页面底色（叠加 22px 点阵） |
| 点阵 | `rgba(154,52,18,.13)` | `body` 背景第一层，`background-size: 22px 22px` |
| 主色橙 | `#F97316` | 导航选中、主按钮、徽标 |
| 缎带深橙 | `#E8590C → #B53C08` | 页头渐变（白字对比 3.4:1，可再深不可再浅） |
| 信任蓝 | `#2563EB` | 第二语义（进行中、信息标签） |
| 卡片 | `#FFFFFF` | 圆角 18px + 双层软阴影 |
| 正文 / 标题 | `#5A2F14` / `#7C2D12` | 暖棕，替代中性灰 |
| 次要文字 | `#9A5B32` | 说明、时间戳 |

造型规则：

1. 圆角 `--ls-radius-sm/md/lg` = 12 / 16 / 20px；卡片 18px。
2. 卡片阴影：`0 10px 24px rgba(154,52,18,.10), 0 2px 0 rgba(154,52,18,.04)`；深色形态收敛为 `rgba(0,0,0,.42)`。
3. 页头 = 橙色缎带（`.hero-panel.sa-page-header` / `.sf-page-head`），白色标题，按钮=白色实心或半透明白描边。
4. 导航：胶囊形，选中为实心橙 + 白字 + 橙色投影；图标块为浅橙圆角块。
5. 深色模式下橙色提亮为 `#FB9D55`，侧栏与顶栏改为暖深棕，点阵同步换暖色。

## 深色模式

深色与主题正交，由 `[data-scheme='dark']` 驱动，写在 theme.css 三套浅色块之后（同权重后出现，覆盖同名字面值）。每套主题另有 `[data-scheme='dark'][data-theme='x']` 的微调块，用于提亮主色、换掉白色内发光、把壳层改成对应色系的深色。

## 常见问题

1. **改颜色改错了层**：卡片描边、圆角、阴影属于造型，去 `theme-directions.css`；只有颜色值属于 `theme.css`。
2. **Naive UI 组件不吃 CSS 变量**：Naive 会把 `--n-*` 写成元素内联样式，样式表里的同名自定义属性改不动它；需要直接给 `background-color` / `border` / `color` 赋值（参考主题方向层里的页头按钮）。
3. **新增一套主题**：在 `theme.css` 加一段 `[data-theme='x']` 变量块 → 在 `theme-directions.css` 加一段造型规则 → 同步 `apps/web/src/utils/themes.ts`、`apps/api/app/services/system_settings.py` 的预设名与描述、`ThemeDrawer.vue` 的色卡。
4. **对比度底线**：橙色/金色大面积色带上的白字，文字不小于 19px 或改用深色字；浅底上的功能色文字一律取该色相的深一档。

插画使用规则：只放在登录页与空状态这类"没有数据也要有画面"的地方；工作页（表格、看板、编辑器）不加插画，活泼来自色彩、字号与留白。

宽屏对齐：内容区 `--ls-content-max` 为 1680px 并居中，墨绿画布的深色页头带用 `100vw` 伪元素铺满 `.sb-body`（`overflow-x: clip` 收边），避免宽屏下色带与侧栏之间空出一条画布色。
