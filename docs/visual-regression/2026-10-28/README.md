# 视觉验收基线（2026-10-28）：教学总览按「这节课」重做

## 本轮改了什么

教学总览不再是一个堆满区块的仪表盘，而是一个**按课堂阶段切换的单页**：上课中只讲这一节课，未开课只讲开课。方案 A（用户选定）。

### 删掉的

| 区块 | 原因 |
| --- | --- |
| 指标条（7 个带边框指标格） | 年级/班级/学生一学期不变；其余 4 项与图表、侧栏完全重复。压成页脚一行文字 |
| 「今日概览」柱状图 | 5 个系列里 4 个就是指标条上的数字 |
| 「近期课堂提交与待评阅」图 | 画的就是「最近课堂」列表，只是换了画法 |
| 页内「快捷入口」4 按钮 + 侧栏「快捷入口」4 按钮 | 左侧导航常驻这些入口，页面上等于同一链接出现 3 次 |
| 页头「学案管理」「进入实时课堂」按钮 | 与主卡操作重复；实时课堂入口只留在主卡 |
| 上课后的「班级码条」 | 班级码并入「这节课」主卡底部 |
| 常驻座位图 | 默认折叠成一行摘要，需要点名时再展开 |

### 现在的结构

- **上课中（8+4 双栏）**：主栏 =「这节课」主卡（班级/课次 → 已签到、已完成提交、待评阅三个大数字 → 班级码 + 开课时间）+ 折叠座位图；右栏 = 今天要处理的（3 行）+ 最近课堂。
- **未开课 / 上一节已结束（单列）**：开课台（整行）→ 今天要处理的（横排三格）→ 最近课堂 → 页脚摘要。整页一屏装完。

### 一并收掉的视觉噪音

- 卡片去阴影，只留 1px 边框与色调分层；圆角统一到 `--ls-radius-md`（14px）。
- 开课台去掉「第一步」徽标、左侧 4px 主色条与径向渐变。
- 11.5px / 700 的小标签改为正常字重；主卡数字提升到 32px，页头班级 24px。
- 座位格 hover 不再位移，只改边框色。

## 实测（1600×1000 视口，Chrome）

| 项 | 改造前 | 改造后 |
| --- | --- | --- |
| 带边框区块数 | 15 | 上课中 4 / 未开课 4 |
| 可点元素 | 约 29（另有左侧导航 14） | 上课中 12 / 未开课 10 |
| 页面总高 | 约 1000–1200px（首屏看得见开课台、指标条和半个课堂卡） | **900px，一屏无滚动** |
| 「进入实时课堂」出现次数 | 3 | 1 |
