# 学生端重设计（2026-10-28）：每页只回答一个问题

## 本轮改了什么

学生端此前是「学案进度 + 4 张等权指标卡 + 图表 + 说明文字 + 档案」的堆叠：同一数字在指标卡、
图表、面板标题里出现 2–4 次，长段说明占据首屏，真正的「现在该做什么」被推到第二屏。
本轮按 [design-taste-frontend] 的 **Achromatic ledger**（seed `440720002`）重做：
壳层与卡片不带品牌色，**品牌绿只标记「当前这一步」**——进行中的任务、进度条、唯一需要比较的数据。

- **底子**：`apps/web/src/styles/student-workspace.css`（学生端令牌 + `sw-*` 结构与行/状态/进度组件）
- **组件**：`apps/web/src/components/student/` 的 `StudentPageHead / StudentPanel / StudentStatStrip / StudentEmpty`
- **壳层**：`StudentLayout` 导航分为 学习 / 资源 / 我的 三组；侧栏与顶栏去阴影、去毛玻璃；
  顶栏只保留当前位置，标签页改成下划线文字页签；主操作按钮统一为近黑填充。

### 全局收掉的视觉噪音

| 收掉的 | 原因 |
| --- | --- |
| 圆角 18–24px 的玻璃卡片、`backdrop-filter`、柔和投影 | 表面只用 1px 描边 + 白色，一层色调差分层 |
| 顶部 4 张等权指标卡（图标方块 + 数字 + 说明） | 合并为一条被 1px 分隔的统计带，最多 4 格 |
| 每张卡标题前的彩色图标方块 | 全部移除，靠标题层级区分 |
| 「这一页展示…」式说明段落、「本页规则」「阅读提示」「常用入口」 | 删除；只保留会改变下一步动作的一句话 |
| 与指标卡同源的图表（完成率环图、参与饼图、状态环图、成绩趋势） | 删除；唯一保留的图表是页面真正的数据主体 |
| 同一动作出现 2–3 次（返回课程、下一任务、撤销评阅、上传） | 各处只留一个入口，其余收进「更多操作」 |

### 每页的「一个问题 → 最大区块 → 一个主操作」

| 页面 | 问题 | 首屏最大块 | 主操作 |
| --- | --- | --- | --- |
| 学习首页 | 现在该做什么 | 「下一步」学案卡（含 学案→任务→提交→评阅 路径） | 开始学习 |
| 课程详情 | 这课有哪些任务、做到哪 | 任务清单（序号 + 类型 + 状态 + 开始） | 继续：下一项任务 |
| 阅读任务 | 读完了吗 | 阅读正文 + 右侧阅读进度 | 标记为已读 |
| 学习任务 | 怎么交 | 任务内容 / 讨论 / 嵌入页 + 作品说明 | 提交作品 |
| 编程任务 | 代码写完怎么交 | 代码编辑区（行/字符/草稿来源） | 提交代码作品 |
| 作品互评 | 投给谁 | 作品墙 + 当前作品详情 | 推荐这份作品 |
| 作品工坊 | 我交了什么、评了吗 | 作品记录表 | 查看详情 / 再次提交 |
| 作品详情 | 这份作品什么状态 | 状态带 + 作品说明 + 附件 | 再次提交 |
| 随堂测验 | 现在能考哪一场 | 可开始测验清单 | 开始测验 |
| 测验排行 | 今天谁考得好 | 完整排行榜 | 返回测验 |
| 打字训练 | 现在练哪篇 | 练习清单 | 开始练习 |
| 打字排行 | 谁打得快 | 速度柱 + 准确率折线（唯一图表） | 切换范围 |
| 课程资源 | 有哪些材料 | 分类 / 列表 / 详情三栏阅读器 | 打开外链 |
| 共享网盘 | 还能传多少、怎么传 | 文件表 + 待上传条 | 上传文件 |
| 小组协作 | 组里谁到课、网盘有什么 | 成员表 + 共享网盘 | 打开小组网盘 |
| 我的档案 | 资料对不对、怎么改 | 资料/签到/安全/修改申请 四个页签 | 保存对应修改 |

## 保持不变

路由、API 调用、提交/上传/下载/删除、讨论发布、计时器、答题弹窗、本地草稿、小组共享草稿、
评阅撤销、`route.query` 同步、权限门控与状态机全部原样；本轮只改模板与页面内样式。
旧的档案地址（`/student/profile/photo|gender|password|class-transfer|attendance`）仍映射到对应页签。

## 实测

- `npx vue-tsc --noEmit`：通过；`npm run check:no-element`：通过；`npx vite build`：通过。
- `lint.mjs --app`：0 FAIL（WARN 为 `box-shadow: none` / `backdrop-filter: none` 的覆盖写法、
  代码编辑器与 `<pre>` 的等宽字体、全局 `.eyebrow` 的重置规则，均属预期）。
- 1440 / 768 / 390 三档：无横向滚动；手机上统计带改 2 列/1 列，左右栏堆叠，学习路径改 2×2。
- 深色模式：表面、描边、按钮反色、状态色均按 `data-scheme=dark` 适配，绿色仍只出现在当前步骤。
