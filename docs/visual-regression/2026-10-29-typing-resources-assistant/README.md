# 教师后台三页重设计（2026-10-29 第二轮）：打字训练 / 资源中心 / AI 助手

## 本轮改了什么

这三页原来的共同问题是：**页头说明 + 4 张等权指标卡 + 装饰图表 + 常驻大表单**，真正的答案
（有哪些练习内容、学生端能看到什么资源、哪些课时配了学伴）被挤到页面下半部或右半边；页头还堆着
「刷新 / 重置表单」等次要按钮。

本轮继续沿用上一轮教师端三页的 **accent-ladder** 结构（`--keep palette,type`）：
品牌色只落在唯一主操作、当前选中项和状态药丸上；面一律白底 + 1px 描边，不加渐变、玻璃和阴影。

- **底子**：`apps/web/src/styles/staff-workspace.css`（`sf-*` 结构），只在 `.staff-layout` 内生效。
- **组件**：`StaffPageHead`（页面唯一 `h1`）与 `StaffStatStrip`（一条被 1px 切开的统计带）。
- 学生端、登录页与其他教师页不受影响。

### 每页一个问题 → 首屏最大块 → 主操作

| 页面 | 问题 | 首屏最大块 | 主操作 |
| --- | --- | --- | --- |
| 打字训练 | 学生端有哪些练习、练了多少、哪套没启用 | 内容清单（模式页签 + 练习/平均/最佳速度列） | 新建内容（抽屉） |
| 资源中心 | 学生端现在能看到什么、哪些还是草稿 | 资源清单（分类页签 + 搜索/类型筛选） | 新建资源（抽屉） |
| AI 助手 | 哪些课时配了学伴、学生对话有没有被拦截 | 课时学伴清单（「对话审计」同层页签） | 新建绑定（抽屉） |

### 删除 / 合并

| 删除或合并的 | 原因 |
| --- | --- |
| 三页各 4 张 `.metric-tile` 指标卡 | 换成一条被分隔线切开的统计带，数字不再和列表争焦点 |
| 打字页「内容练习与成绩对比」柱+线图 | 只有一套内容时图上只有一根柱；练习次数、平均/最佳速度已在行里 |
| 资源页「分类资源分布」柱+线图 | 与分类页签上的计数、资源行的状态重复 |
| 打字页左边的常驻「新建内容」表单 | 收进右侧抽屉，内容清单占满整行 |
| 打字页 9 个班级圆角标签横排 | 班级数量进统计带，正文区不再被标签占一行 |
| 资源页「新建分类 / 分类列表 / 新建资源 / 资源列表」四块平铺 | 资源清单为主，分类收进右侧窄栏；两个表单收进抽屉；正文预览改成弹窗 |
| 资源页底部的常驻正文预览框 | 行点击或「预览」打开弹窗，列表不再被预览区推长 |
| AI 助手页左边的常驻「新建绑定」表单 | 收进右侧抽屉，绑定清单回到首屏 |
| AI 助手的 `n-tabs` + `n-data-table` | 换成 `sf-tabs` + 行列表，班级/学案/知识库合进一行的说明 |
| 页头「刷新数据 / 重置表单」 | 重置表单随抽屉关闭自然消失；刷新收进面板标题右侧的小按钮 |
| 表格斑马纹、表头填充带、18px 圆角卡片 | 用行分隔线与对齐代替 |

### 顺带修掉

- 右下角「小榉」悬浮球的 `z-index` 从 2100/2090 降到 1900/1890（`styles/assistant.css`）。
  此前它会盖住抽屉底部的「保存 / 创建绑定」按钮；抽屉和弹窗（2000+）现在会正常压住它。

## 实测（1440×900，DOM 实测）

| 页面 | 改前 | 改后 |
| --- | --- | --- |
| 打字训练 | 4 指标卡 + 图表 + 左表单右列表，内容和表单都超出首屏 | **900px 一屏**；统计带 + 模式页签 + 6 行内容 |
| 资源中心 | 4 指标卡 + 图表 + 两块大表单，资源列表在 1500px 之后 | **995px**；统计带 + 资源清单（8 行）+ 分类窄栏 |
| AI 助手 | 左侧大表单 + 右侧空表格，绑定操作不在首屏 | **900px 一屏**；统计带 + 4 行课时学伴；审计为同层页签 |

三档宽度（1440 / 768 / 390）均无横向滚动；390 下统计带为 2×2，行改成「标题 + 带标签的数值」两行，
页签横向滚动；手机上行内的「班级 / 场景 / 消息 / 拦截 / 最近活跃」都带字段名，不出现孤立数字。

### 规则核查（DOM 实测，`main` 范围内）

- **0 个阴影、0 个渐变、0 个 canvas**；圆角只有 10px（卡片/控件）与 4px（药丸）。
- **没有小于 11px 的文字**；大号数字使用 `font-variant-numeric: tabular-nums`。
- 每页 **1 个 `h1`**，没有 eyebrow、序号和等权卡片网格。
- 1440 / 390 下 `scrollWidth === clientWidth`，无横向滚动。
- 行点击与行内「查看 / 预览 / 查看对话」按钮并存；键盘走行内按钮，避免嵌套交互元素。
