# 教师后台三页重设计（2026-10-29）：学案管理 / 课程内容 / 测验题库

## 本轮改了什么

这三页原来的共同问题是：**页头说明 + 4 张等权指标卡 + 装饰图表 + 多个表单平铺**，真正的答案（学案清单、
课次绑定、已发布测验）被挤到下面或右半边，页头还堆着 3–6 个次要按钮。

本轮沿用上一轮学生端的 **accent-ladder**（seed `1681571933`，`--keep palette,type`）：
品牌色只落在小标记上——唯一主操作、当前选中项、状态药丸；面一律白底 + 1px 描边，去掉渐变、玻璃与阴影。

- **底子**：`apps/web/src/styles/staff-workspace.css`（`sf-*` 结构：页头 / 统计带 / 面板 / 行 / 表头 / 页签），只在 `.staff-layout` 内生效。
- **组件**：`apps/web/src/components/staff/StaffPageHead.vue`（页面唯一 `h1`）与 `StaffStatStrip.vue`（一条被 1px 切开的统计带）。
- 其余教师页不受影响：`SaPageHeader` / `SaPanel` 原样保留，只有这三页换成新页头。

### 每页一个问题 → 首屏最大块 → 主操作

| 页面 | 问题 | 首屏最大块 | 主操作 |
| --- | --- | --- | --- |
| 学案管理 | 哪份学案还没发布、还没绑课次 | 学案清单（表头 + 右对齐任务/待完成列） | 新建学案 |
| 课程内容 | 这套教材里哪个课次还没学案 | 教材页签 + 单元课次清单 | 新建学案 |
| 测验题库 | 有哪些测验、题库里有多少题 | 「已发布测验」/「题库与题目」两个页签 | 发布测验 |

### 删除 / 合并

| 删除的 | 原因 |
| --- | --- |
| 学案页 2 张 ECharts（整体完成率环图、各学案进度柱图） | 与统计带、清单里的数字重复；清单本身是答案 |

| 课程页「展开/收起全部教材、全部单元」4 个按钮 | 页签切换已替代 |
| 测验页 3 个常驻表单（新建题库 / 添加题目 / 发布测验） | 收进右侧抽屉，列表回到首屏 |

## 实测（Chrome headless + CDP，1440×900）

| 页面 | 改前 | 改后 |
| --- | --- | --- |
| 学案管理 | 1003px；4 指标卡 + 2 图表 + 表格；页头 3 按钮；无 h1 | **900px 一屏**；统计带 + 清单；页头 1 主 1 次；有 h1 |
| 课程内容 | 2956px；4 指标卡 + 双层折叠；页头 6 按钮；无 h1 | **1856px**；统计带 + 教材页签 + 课次清单；页头 2 按钮；有 h1 |
| 测验题库 | 2408px；4 指标卡 + 图表 + 7 块面板；3 个常驻表单 | **900px 一屏**；统计带 + 两个页签；表单进抽屉 |

三档宽度（1440 / 768 / 390）均无横向滚动；手机上统计带为 2×2，行改成「标题 + 带标签的数值」两行，
表格在手机上不出现（测验列表本身已是行列表）。

### 规则核查（DOM 实测）

- 三页 **0 个阴影、0 个渐变**；圆角只有 10px（卡片/控件）与 4px（药丸）。
- **没有小于 11px 的文字**；所有大号数字都带 `font-variant-numeric: tabular-nums`。
- 有彩色的背景元素每页只剩 **1 个**（主操作按钮）。
- 次要文字 `--sf-muted` 在白色与主题浅底上都达到 4.5:1。
