# 系统设置页重排（2026-10-29）：每个子页面只讲一件事

## 本轮的问题

原来是一个页头 + 7 个横向页签，每个页签下面平铺 2–4 张带阴影的大卡片：

- **基础参数**：11 个字段单列拉满 700px 宽，右侧「当前统计」是 5 个带边框的指标格，往下 500px 全是空白。
- **班级与教师**：三个巨型卡片串在一起（班级表 + 班级权限表单 / 教师表 + 教师编辑表单 / 学生表），
  同一个「编辑教师」「设置班级权限」各有表单版和弹窗版两套入口；「批量导入学生」放到了教师卡片里。
- **机房与座位**：左边「机房管理」只有 4 个单选按钮，占了一半宽度，右边座位板被挤在 700px 里，
  整页 4827px 高。
- **AI 模型服务**：代理、提示词、运行参数、服务列表四张大卡片竖直堆叠，2183px，谁都不像主角。
- **教材目录 / 升班与归档 / AI 安全**：同样是「一屏里塞满等权卡片」。

另一个共同问题：`n-form-item` 里的说明文字被挤在输入框右侧（naive 的 blank 区是 flex 行），
每行字段看起来像被截断。

## 现在的结构

外壳改成 **左侧分组导航 + 右侧单一焦点内容区**：

| 分组 | 子页面 | 页面回答的一个问题 | 主操作 |
| --- | --- | --- | --- |
| 学校 | 基础参数 | 这个平台的基本设置是什么 | 保存参数 |
| 人员与班级 | 班级 / 教师 / 学生 | 这个班的名单和权限对不对 | 新增班级 / 新增教师 / 批量导入 |
| 人员与班级 | 升班与归档 | 哪些班能升、升完留不留下记录 | 执行升班 |
| 课堂资源 | 机房与座位 | 这个机房的座位和 IP 怎么排 | 保存座位表 |
| 课堂资源 | 教材目录 | 这套教材里有哪些单元和课次 | 新增教材 |
| AI 应用 | AI 模型服务 | 接的是哪个模型、提示词和参数是什么 | 新增服务 / 保存 |
| AI 应用 | AI 安全 | 学生能发多少条、哪些词会被拦 | 保存安全设置 |

- 「班级与教师」拆成 **班级 / 教师 / 学生** 三个独立子页面（后台路由 `?tab=classes|teachers|students`，
  旧的 `?tab=accounts` 仍会落到「班级」），每页一个列表即答案。
- 基础参数按语义分成四块：学校信息 / 功能开关 / 小组网盘 / 转班用语预设，字段两列排布，
  说明文字落到字段下方（`#feedback`）。
- 机房与座位合成一个工作区：机房变成页签，座位板全宽，座位明细表默认收起（按需展开）。
- AI 模型服务加子页签：模型服务 / 学伴提示词 / 运行参数，代理配置收在服务列表底部。
- 「当前统计」不再单独占一张卡：5 个数字已经同时出现在页头一行事实和左侧导航的计数里。

## 删掉 / 合并的

| 删除的 | 原因 |
| --- | --- |
| 「编辑教师信息」内联表单（约 70 行模板 + 5 个状态） | 与「新增/编辑教师」弹窗字段完全相同，同一动作两个入口 |
| 「按班级保存资料修改权限」内联表单 | 与表格里的「权限设置」弹窗重复 |
| 教师卡片里的「下载学生模板 / 批量导入学生」 | 属于学生页，已移入学生子页面 |
| 5 个 `.metric-tile` 边框指标格 | 换成页头一行事实 + 侧栏计数 |
| 「资料修改权限」4 个圆角标签列 | 改成一句可读文案（全部开放 / 姓名、性别 / 全部禁止） |
| 座位明细表常驻（49 行） | 默认收起，需要批量改 IP 时再展开 |
| 教材卡片的圆角卡片套圆角标签 | 改成书 → 单元 → 课次三层行，课次用胶囊条 |
| 表头色带、斑马纹、18px 卡片圆角 + 阴影 | 统一为 `sf-*`：白底 + 1px 描边 + 行分隔线 |

| 班级（原「班级与教师」） | 3424（三卡合一） | **904** |

三档宽度（1440 / 768 / 390）都没有横向溢出；页面上 0 个渐变、0 个卡片阴影
（只剩开关滑块这类表单控件自带的阴影），最小字号 11px。
